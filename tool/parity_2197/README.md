# Parity check for the home_row_card_image.dart move

Not meant to be merged. This sits on top of the PR branch so the move can be
checked against the code it came from.

`tool/parity_2197/run.sh` (from the repo root, after `flutter pub get`):

1. Runs `harness_test.dart` against the moved public helpers and saves every
   result as JSON.
2. Puts back the old `lib/ui/screens/home/home_screen.dart` from upstream
   `8dfd2e8d2`, adds a few static test hooks to `HomeScreen` so a test can reach
   the old private helpers (`old_hooks.dart.txt`), and runs the same harness.
3. Restores the file and compares the two results case by case with
   `compare.dart`. It prints the case count per helper and exits 1 on any
   difference.

The harness feeds every item type with each combination of image tags,
series, parent and representative-item fields, Seerr items, every image type,
several card heights, scales, series thumbs on and off, and My Media on and
off; plus every row type and id under seven settings combinations.

`facade.dart` is generated by the script, so the harness doesn't analyze
cleanly on its own.
